How sorting works

Score and clock sorts prioritize live games. Clock-based sorts place MLB, tennis, untimed CFB overtime, and missing clocks after games with usable clocks. Future overtime is unknown; ratios use a one-second minimum. For metric sorts, stale scores sort last. Start-time sorting uses ESPN’s listed start time.
