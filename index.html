How sorting works

Score and clock sorts prioritize live games. Clock-based sorts place MLB, tennis, soccer, shootouts, untimed CFB overtime, and missing clocks after games with usable clocks. Soccer match clocks are shown on cards, but added time makes a precise countdown unavailable. Future overtime is unknown; ratios use a one-second minimum. For metric sorts, stale scores sort last. Start-time sorting uses ESPN’s listed start time.
